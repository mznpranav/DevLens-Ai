# DevLens AI - Your Codebase, Explained Like a Story

DevLens AI is an AI-powered codebase onboarding co-pilot that transforms any GitHub repository into an interactive, intelligent explainer. It provides developers with visual architecture maps, AI-generated narratives, complexity heatmaps, and an ask-anything chat interface to understand any codebase instantly.

## Features

### 1. **Visual Architecture Map**
Interactive dependency graph displaying modules, file relationships, and data flow. Nodes are color-coded by file type and complexity, making it easy to understand the codebase structure at a glance.

### 2. **AI Narrative Summary**
Claude-powered plain-English explanation of the entire codebase covering:
- Entry points and initialization flow
- Authentication mechanisms
- Data layers and persistence
- Security considerations and flagged gaps

### 3. **Ask-Anything Chat Sidebar**
Context-aware natural language Q&A panel that:
- Answers questions about any part of the repository
- Includes file and line number references
- Maintains conversation history
- Understands the full codebase context

### 4. **Smart Onboarding Path**
Role-based step-by-step reading guide generated by AI:
- **Frontend**: Start with UI entry points, component structure, state management
- **Backend**: Start with server initialization, API routes, data models
- **DevOps**: Start with deployment configuration, infrastructure, CI/CD

### 5. **Complexity Heatmap**
Risk scoring visualization highlighting:
- Most complex files and modules
- Undocumented code sections
- Untested components
- Percentage-based risk scores for quick assessment

### 6. **Analysis Persistence**
- Store repository analysis results in the database
- Revisit previously analyzed repositories instantly
- Build a library of analyzed codebases
- Track analysis history per user

## Tech Stack

### Frontend
- **React 19** with TypeScript
- **Tailwind CSS 4** for styling
- **shadcn/ui** for component library
- **tRPC** for type-safe API communication
- **Wouter** for routing
- **Framer Motion** for animations

### Backend
- **Express 4** for HTTP server
- **tRPC 11** for RPC procedures
- **MySQL/TiDB** for persistent storage
- **Drizzle ORM** for database management
- **Claude API** for AI-powered analysis

### Infrastructure
- **Manus OAuth** for authentication
- **GitHub REST API** for repository data
- **Built-in LLM** for code analysis and narrative generation

## Getting Started

### Prerequisites
- Node.js 22+
- pnpm 10+
- GitHub account
- MySQL/TiDB database

### Installation

1. **Clone and install dependencies:**
   ```bash
   cd devlens-ai
   pnpm install
   ```

2. **Set up environment variables:**
   The following environment variables are automatically provided by Manus:
   - `DATABASE_URL`: Database connection string
   - `JWT_SECRET`: Session signing secret
   - `VITE_APP_ID`: OAuth application ID
   - `OAUTH_SERVER_URL`: OAuth server URL
   - `BUILT_IN_FORGE_API_URL`: LLM API endpoint
   - `BUILT_IN_FORGE_API_KEY`: LLM API key

3. **Initialize the database:**
   ```bash
   pnpm drizzle-kit generate
   pnpm drizzle-kit migrate
   ```

4. **Start the development server:**
   ```bash
   pnpm dev
   ```

   The application will be available at `http://localhost:3000`

## Usage

### For Users

1. **Visit the Landing Page**: Navigate to the home page to learn about DevLens AI
2. **Sign In**: Click "Get Started" and authenticate with your Manus account
3. **Analyze a Repository**: 
   - Paste any GitHub repository URL (public or private)
   - Wait for the AI analysis to complete (typically 30-60 seconds)
4. **Explore the Analysis**:
   - Read the AI narrative summary
   - View the architecture map
   - Check the complexity heatmap
   - Follow the smart onboarding path for your role
   - Ask questions in the chat sidebar

### For Developers

#### Adding New Features

1. **Update the database schema** in `drizzle/schema.ts`
2. **Generate migrations**: `pnpm drizzle-kit generate`
3. **Apply migrations**: `pnpm drizzle-kit migrate`
4. **Add query helpers** in `server/db.ts`
5. **Create tRPC procedures** in `server/routers.ts` or feature-specific routers
6. **Build frontend components** in `client/src/pages/` or `client/src/components/`
7. **Write tests** in `server/*.test.ts`
8. **Run tests**: `pnpm test`

#### Running Tests

```bash
# Run all tests
pnpm test

# Run tests in watch mode
pnpm test --watch

# Run specific test file
pnpm test server/analysis.test.ts
```

#### Building for Production

```bash
# Build the application
pnpm build

# Start the production server
pnpm start
```

## API Reference

### Analysis Endpoints

#### `analysis.analyzeRepository`
Analyze a GitHub repository and generate all insights.

**Input:**
```typescript
{
  repoUrl: string; // GitHub URL or owner/repo format
}
```

**Output:**
```typescript
{
  analysisId: number;
  status: "completed" | "processing" | "failed";
}
```

#### `analysis.getAnalysis`
Retrieve a completed analysis with all generated insights.

**Input:**
```typescript
{
  analysisId: number;
}
```

**Output:**
```typescript
{
  id: number;
  narrative: string;
  architectureMap: { nodes: [], edges: [] };
  heatmap: Array<{ file: string; riskScore: number }>;
  status: string;
}
```

#### `analysis.chatWithCode`
Send a message to the AI about the analyzed codebase.

**Input:**
```typescript
{
  analysisId: number;
  message: string;
}
```

**Output:**
```typescript
{
  message: string;
  fileReferences: Array<{ file: string; line: number }>;
}
```

#### `analysis.getOnboardingPath`
Get the role-based onboarding path for a repository.

**Input:**
```typescript
{
  analysisId: number;
  role: "Frontend" | "Backend" | "DevOps";
}
```

**Output:**
```typescript
{
  role: string;
  steps: string[];
}
```

## Troubleshooting

### Database Connection Issues
- Verify `DATABASE_URL` is set correctly
- Check database credentials and network access
- Ensure database is running and accessible

### OAuth Login Fails
- Verify `VITE_APP_ID` and `OAUTH_SERVER_URL` are correct
- Check that redirect URLs are properly configured
- Clear browser cookies and try again

### Analysis Fails
- Verify GitHub repository URL is correct and accessible
- Check that GitHub API rate limits haven't been exceeded
- Ensure LLM API is responding (check `BUILT_IN_FORGE_API_URL`)

### Tests Fail
- Run `pnpm install` to ensure all dependencies are installed
- Clear node_modules and reinstall if issues persist
- Check that database is running for integration tests
